# CMOS 2-to-1 Multiplexer Design Using Cadence Virtuoso

## Project Overview
This project presents the design and physical verification of a CMOS 2-to-1 multiplexer (MUX) using Cadence Virtuoso and gpdk045 (45 nm) technology.

## Tools and Technology
- Cadence Virtuoso
- gpdk045 (45 nm) CMOS technology

## Design Flow
- Schematic Design
- Symbol Generation
- Circuit Simulation
- Physical Layout Design
- Design Rule Check (DRC)
- Layout Versus Schematic (LVS)

## Project Objectives
- Design a CMOS 2-to-1 multiplexer.
- Implement the physical layout.
- Verify the layout using DRC and LVS.

## Future Improvements
- Analyze power consumption.
- Measure propagation delay.
- Compare pre-layout and post-layout simulation results.
- Investigate parasitic effects.
